# Al-Wassouf — متجر الوسوف

مشروع Monorepo لموقع متجر عربي متجاوب باتجاه RTL، وREST API مبني على NestJS وMongoDB. إدارة المنتجات والفروع والعروض والإعدادات والحسابات الإدارية متاحة من لوحة تحكم ويب واحدة في `/admin`؛ لا توجد خدمة بوت مستقلة.

## المتطلبات

- Node.js 20 أو أحدث وnpm 10+
- MongoDB 7 محليًا أو MongoDB Atlas
- متغيرات بيئة آمنة لحساب الإدارة وجلسات الدخول

## التشغيل محليًا

```bash
cp .env.example .env
npm install
docker compose up -d mongodb
```

أنشئ سر الجلسات وكلمة مرور قوية للمالك في `.env` (كلمة المرور لا تقل عن 12 حرفًا):

```bash
openssl rand -hex 32
```

ضع الناتج في `SESSION_SECRET`، ثم عيّن `ADMIN_USERNAME` و`ADMIN_PASSWORD` و`ADMIN_DISPLAY_NAME`. بعد ذلك شغّل التهيئة:

```bash
npm run seed
```

التهيئة قابلة لإعادة التشغيل وتحافظ على المنتجات والفروع والإعدادات الحالية. لا تُنشئ منتجات تجريبية ولا تستبدل كلمة مرور المالك عند إعادة التشغيل إلا عند ضبط `ADMIN_RESET_PASSWORD=true`.

شغّل API والموقع في نافذتين:

```bash
npm run dev:api
npm run dev:web
```

- الموقع: `http://localhost:3000`
- لوحة التحكم: `http://localhost:3000/admin`
- صحة API: `http://localhost:4000/health`
- توثيق المسارات: [`apps/api/API_NOTES.md`](apps/api/API_NOTES.md)

تستخدم الواجهة مسارات `/api` نسبية، ويحوّلها Next.js إلى API من جهة الخادم. عند النشر، عيّن `API_BASE_URL` إلى عنوان API الذي يستطيع خادم Next الوصول إليه. يجب حفظ مجلد الصور `apps/api/uploads` (أو قيمة `MEDIA_DIR`) على قرص دائم ونسخه احتياطيًا.

## ما تديره لوحة التحكم

- **المنتجات:** إنشاء وتعديل ونشر وإخفاء وأرشفة الهواتف مع الاحتفاظ بالسجلات والصور والمخزون؛ حقول الاسم والماركة والموديل والوصف والمواصفات والسعر الاختياري، ورفع حتى 8 صور للطلب (JPG/PNG/WebP/GIF، بحد 8 ميغابايت لكل صورة). يعرض المحرر معاينة مباشرة قبل النشر.
- **التوفر:** سجل منتج واحد لكل هاتف، مع كمية وحالة توفر مستقلتين لكل فرع. تتحقق واجهة API من هوية المنتج والفرع والكمية، ويُمنع تكرار الفرع في الطلب.
- **الفروع:** إضافة وتعديل وإيقاف وحذف الفروع، وإدارة العناوين وWhatsApp والهاتف والبريد ومعلومات التواصل وروابط القنوات والخرائط. لا يُحذف فرع مرتبط بسجلات توفر؛ يمكن إيقافه للحفاظ على السجل.
- **العروض والصور:** إدارة العروض ومدة ظهورها وصورها وروابط الإجراء، ورفع صورة للواجهة من إعدادات المتجر.
- **الإعدادات والإحصائيات:** معلومات المتجر، العملة، سياسة إظهار السعر/الكمية، روابط التواصل، إحصاءات الاستخدام وسجل النشاط.
- **الفريق:** حسابات باسم مستخدم وكلمة مرور، أدوار مالك/مدير/محرر/مسؤول مخزون، وتعطيل الجلسات وإمكانية تغيير كلمة المرور. كلمات المرور مخزنة باستخدام scrypt، والجلسات موقعة ومحمية بملف ارتباط HttpOnly وSameSite.

## الصور والبيانات الموجودة

الصور الجديدة تحفظ كملفات محلية خارج MongoDB، وتُخدم عبر `/api/media/:filename` بعد التحقق من نوع الصورة وفك ترميزها وتنظيفها. التهيئة لا تحذف أي سجل منتج أو فرع أو إعداد موجود، ولا تمسح مجموعات البيانات القديمة. إذا كانت هناك صور منتج قديمة على Telegram، استوردها لمرة واحدة قبل إزالة التوكن: `TELEGRAM_BOT_TOKEN='<temporary-token>' npm run migrate:legacy-media` على بيئة تصل إلى MongoDB ومجلد `MEDIA_DIR` الدائم نفسه. تُحدّث الأداة مراجع الصور مع الاحتفاظ بالسجلات الأصلية؛ ما يتعذر استيراده يظهر في التقرير ويمكن إعادة رفعه من لوحة التحكم. لا يعتمد الموقع أو API التشغيلي على Telegram بعد إتمام الاستيراد. احتفظ بنسخة احتياطية من مجلد `MEDIA_DIR` وقاعدة MongoDB معًا.

```bash
npm run typecheck

```
